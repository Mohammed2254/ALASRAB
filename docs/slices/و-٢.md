## ١. المتطلبات

| FR | نصّه | المصدر |
|---|---|---|
| **FR-004** | المشرف يعيد تعيين PIN — **لا استعادة ذاتية** | `SCOPE.md:289` |

**وتفصيله في `ARCHITECTURE.md` §٧.٥:** رمزٌ جديد **يُعرض مرّة واحدة** · **كل
الجلسات تُبطَل** · **يُسجَّل في `audit_log` منسوبًا — بلا قيمة الـPIN**.

## ٢. تدفّق المستخدم

```
المشرف يفتح شاشة الطلاب
  └─ يختار طالبًا ← «إعادة تعيين الرمز»
       ├─ الرمز الجديد يُعرض **مرّة واحدة** — ولا سبيل لاسترجاعه بعدها
       ├─ كل جلسات الطالب تُبطَل فورًا
       └─ سطرٌ في سجلّ التدقيق منسوب **للمشرف** لا للطالب
الطالب على جواله ⇒ ٤٠١ في الطلب التالي
```

## ٣. تدفّق البيانات

```
POST /api/admin/users/{id}/reset-pin
  └─ @admin_required (مستوى الجمعية — §٧.٣)
  └─ services/auth.reset_pin(org, target_user, actor_id)
       ├─ توليد رمز عشوائي من أربعة أرقام
       ├─ set_pin()  → users.pin_hash (argon2id · لا نصّ صريح)
       ├─ UPDATE sessions SET revoked = true WHERE user_id = target
       └─ services/audit.record(kind='pin_reset', actor=المشرف, before=NULL, after=NULL)
  └─ الرمز في الردّ **مرّة واحدة**
```

**ولا `ledger` ولا `point_events`** — التدقيق ليس عملة.

## ٥. الجداول

**جديد واحد** — بمخطّط `DATABASE.md:284` **بلا تعديل**:

```sql
audit_log(id, org_id, kind, summary, before JSONB, after JSONB, actor_id, at)
```

**ولماذا يعمّم على الثلاثة بلا عمود إضافي:**

| المستهلك | ما يحتاجه | كيف يستوعبه المخطط |
|---|---|---|
| **FR-004** (يكتب) | فاعل · هدف · **بلا حمولة** | `kind='pin_reset'` · `before`/`after` **فارغان** |
| **FR-037** (يكتب) | «منسوبًا ومؤرَّخًا» + مرجع الحدث | `actor_id` · `at` · مرجع في `after` |
| **FR-084** (يقرأ) | قائمة زمنية مرئية للمشرفين | فهرس `(org_id, at)` |
| تغيير الأوزان (و-٧) | **إصدار قبل/بعد** — علّة وجود السجلّ (§٣.٣) | `before`/`after JSONB` |

> **ورُفض `target_user_id`** رغم ملاءمته لإعادة التعيين: **يضيق عن تغيير
> الأوزان** الذي لا هدف مفردًا له. مكانه `after JSONB` — و`kind` نصّ مفتوح
> **صفوف لا كود**، كما `activity_type` في ADR-005.

**يُقرأ ولا يُعدَّل:** `users` · `sessions`.

## ٧. معايير القبول

| ق-٤٠ | إعادة التعيين تردّ رمزًا جديدًا **مرّة واحدة**، والقديم لا يعمل | رمزٌ يبقى صالحًا بعد إعادة تعيينه |
|---|---|---|
| ق-٤١ | **كل جلسات الطالب تُبطَل** — نفس الكوكي ⇒ `401` | جوالٌ ضائع يبقى داخلًا |
| ق-٤٢ | سطر `audit_log` بـ`kind='pin_reset'` منسوب **للمشرف لا للطالب** | سجلٌّ ينسب الفعل لضحيّته |
| ق-٤٣ | **`before`/`after` فارغان** ولا يظهر الرمز في السجلّ | تسريب الرمز في التدقيق |
| ق-٤٤ | **غير مشرف ⇒ `403` · بلا كوكي ⇒ `401` · طالب مجهول ⇒ `404`** | أي طالب يُصفّر رمز زميله |
| ق-٤٥ | شاشة إعادة التعيين **بلا حساب أعمال** وتجتاز القياس @٣٧٥px | نصّ يُقصّ · هدف لا يُلمس |
