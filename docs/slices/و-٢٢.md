# و-٢٢ — تنظيفٌ معماريّ وبوّابة المتطلَّبات

> الخطّة والقياسات الكاملة في `~/.claude/plans/` — وهذه الوثيقة معاييرُها
> ومالكوها.

**السبب المقيس:** المعايير (`ق`) محروسةٌ بالكامل (٢٧٥/٢٧٥) و**المتطلَّبات
(`FR`) كانت بلا بوّابةٍ واحدة**، و`TRACEABILITY.md` — الجسر — تعفّن شهرًا.
فـ«٢٧٥/٢٧٥ أخضر» كان يُقرَأ اكتمالًا وهو ليس كذلك.

**وليس التضخُّم:** الكودُ الحيّ ١٣٣١١ سطرًا لـ٥٧ مسارًا و٤١ شاشة و٢٦ جدولًا —
**٨٥ سطرًا لكل نقطة نهاية** عبر كل الطبقات، وهو دون المعتاد. والشحمُ المقيس
~٨٪، كلُّه boilerplate لا منطق.
