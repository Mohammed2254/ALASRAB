# و-٣ — سجلّ أحداث الطالب

> **الحالة:** ✅ منفَّذة · **مسار سريع** بعد فرزٍ نظيف الثلاثة.
> **المتطلَّب:** FR-012 (`SCOPE.md:293`) · MUST · قصّة ط-٤.

---

## الفرز — لماذا المسار السريع

| السؤال | الجواب | الدليل |
|---|:--:|---|
| جدول جديد أو هجرة؟ | **لا** | `point_events` منشأ منذ و-١ |
| قيد جديد في القاعدة؟ | **لا** | خانة الثوابت في `TRACEABILITY.md:27` فارغة |
| يمسّ `ledger` أو يكتب؟ | **لا** | **قراءة خالصة** — التصحيحات موجودة أصلًا، والمتطلَّب **عرضها لا إنشاؤها** |

## ١. المتطلبات

| FR | نصّه | المصدر |
|---|---|---|
| **FR-012** | سجلّ أحداث الطالب **شاملًا التصحيحات السالبة** | `SCOPE.md:293` · ط-٤ |

**معيار القصّة:** «التصحيحات تظهر بمقدارها السالب وسببها — **إخفاؤها هو ما
يثير الشك لا إظهارها**».

## ٢. تدفّق المستخدم

```
الطالب يفتح بطاقته
  └─ يرى «سجلّ ساعاتي» تحت البطاقة مباشرةً
       ├─ آخر عشرة أحداث، الأحدث أوّلًا
       ├─ كل حدث: نوعه · مقداره · تاريخ وقوعه
       └─ التصحيح **بالأحمر وبإشارته السالبة وسببه المكتوب**
```

## ٣. تدفّق البيانات

```
GET /api/me/events?limit=N
  └─ @login_required → g.user (الهوية من الجلسة لا من الطلب)
  └─ services/deck.recent_events(org_id, user_id, limit)
       └─ SELECT ... WHERE scope='individual' ORDER BY occurred_at DESC, id DESC
  └─ EventsSchema → JSON
```

**قراءة خالصة.** لا `ledger`، ولا `INSERT`، ولا هجرة.

### ٨.٢ الإثبات العدائي — مُنفَّذ

| المعيار | المخالفة | السقوط |
|---|---|---|
| ق-٢٧أ | `order_by(...asc())` | `assert ['reading','quran'] == ['quran','reading']` |
| ق-٢٧ب | تعطيل `.limit(limit)` | `assert 5 == 3` |
| ق-٢٧ج | عنصر وهمي عند الفراغ | `assert r.json["events"] == []` |
| ق-٢٨أ | `abs(e.delta)` | `assert '40.00' == '-40.00'` |
| ق-٢٨ب | `"reason": None` | `assert None == 'خطأ في تصدير راصد'` |
| ق-٢٩أ | `user_id` من `request.args` | `assert ['777.00'] == ['10.00']` |
| ق-٢٩ب | الحارس يردّ `403` بدل `401` | `assert 403 == 401` |
| ق-٣٠ | `r.pages * 0.15` | `عمليات حسابية (*) · أرقام مجال (0.15)` |
| ق-٣١ | زرّ `h-[40px]` | `ق-١٤: «» 343×40 < 44` |

**ق-٢٧ بثلاث مخالفات وق-٢٨ باثنتين** — لأن نصّيهما يدّعيان أكثر من سلوك:
ق-٢٧ يذكر «**والقائمة الفارغة `200` لا خطأ**»، وق-٢٨ يقرن «**بمقداره السالب**»
بـ«**وسببه**». **والمقياس نصّ المعيار لا عدد دوالّه.**

> **ولم يُسقَط شقٌّ بحجّة «مُثبَت بوسيلة أخرى».** الإشارة السالبة بدت مغطّاة
> بالقياس البصري، وليست كذلك: القياس تحقّق من `dir=ltr` — **موضع الشرطة على
> الشاشة** — لا من أن الـAPI يردّ قيمة سالبة. ولو ردّ `abs()` لمرّ الفحص البصري.

> **وأُعيد تصميم مخالفة ق-٢٩ب:** أوّلها (حذف الحارس) أسقط الاختبار بـ`500` —
> **انهيارًا لا مخالفة نظيفة**. فصارت `abort(403)` بدل `abort(401)`، لتعزل
> الادّعاء («٤٠١ تحديدًا») بلا كسر المسار.

والفحص البصري **لا يُسقَط**: هو ما أمسك عيب `Login.jsx` الذي عمي عنه ق-١٣ نفسه.
