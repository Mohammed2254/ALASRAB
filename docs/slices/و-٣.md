# و-٣ — سجلّ أحداث الطالب

> **الحالة:** ✅ منفَّذة · **مسار سريع** بعد فرزٍ نظيف الثلاثة.
> **المتطلَّب:** FR-012 (`SCOPE.md:293`) · MUST · قصّة ط-٤.

---

## الفرز — لماذا المسار السريع

| السؤال | الجواب | الدليل |
|---|:--:|---|
| جدول جديد أو هجرة؟ | **لا** | `point_events` منشأ منذ و-١ |
| قيد جديد في القاعدة؟ | **لا** | خانة الثوابت في `TRACEABILITY.md:27` فارغة |
| يمسّ `ledger` أو يكتب؟ | **لا** | **قراءة خالصة** — التصحيحات موجودة أصلًا، والمتطلَّب **عرضها لا إنشاؤها** |

---

## ١. المتطلبات

| FR | نصّه | المصدر |
|---|---|---|
| **FR-012** | سجلّ أحداث الطالب **شاملًا التصحيحات السالبة** | `SCOPE.md:293` · ط-٤ |

**معيار القصّة:** «التصحيحات تظهر بمقدارها السالب وسببها — **إخفاؤها هو ما
يثير الشك لا إظهارها**».

## ٢. تدفّق المستخدم

```
الطالب يفتح بطاقته
  └─ يرى «سجلّ ساعاتي» تحت البطاقة مباشرةً
       ├─ آخر عشرة أحداث، الأحدث أوّلًا
       ├─ كل حدث: نوعه · مقداره · تاريخ وقوعه
       └─ التصحيح **بالأحمر وبإشارته السالبة وسببه المكتوب**
```

## ٣. تدفّق البيانات

```
GET /api/me/events?limit=N
  └─ @login_required → g.user (الهوية من الجلسة لا من الطلب)
  └─ services/deck.recent_events(org_id, user_id, limit)
       └─ SELECT ... WHERE scope='individual' ORDER BY occurred_at DESC, id DESC
  └─ EventsSchema → JSON
```

**قراءة خالصة.** لا `ledger`، ولا `INSERT`، ولا هجرة.
