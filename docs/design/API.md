# واجهة الـAPI (Stage 3)

> **القاعدة:** كل endpoint يقابل متطلَّبًا، وكل متطلَّب له endpoint. الفجوات تُعلَن.
> **التوليد:** `flask-smorest` يولّد OpenAPI من `schemas/` — **العقد من الكود لا
> بجانبه**، فلا يفترقان بعد شهر.

---

## ١. قواعد عامّة

| | |
|---|---|
| الجذر | `/api` |
| الترميز | JSON · UTF-8 |
| المصادقة | كوكي جلسة `HttpOnly` — **لا ترويسة `Authorization`** |
| التواريخ | ISO-8601 بـUTC في النقل · **العرض بتوقيت المنظمة في الواجهة** |
| الأرقام | نصّ عشري للمبالغ (`"12.50"`) — **لا `float`** فلا يفقد الدقّة في JS |
| الترقيم | `?limit&cursor` حيث تكبر القائمة |

**كل طلب غير `GET`/`HEAD`** يمرّ بفحص `Origin` — **وغيابها رفضٌ لا تساهل**
(`403`). طبقة ثانية فوق `SameSite=Lax` (ADR-006).

**حدود المعدّل:** `/auth/login` ٥/١٥د · `/notes` ١٠/ساعة · `/me/readings` ٢٠/يوم.
تجاوزها `429` **يذكر متى يُفتح**.

**كل ردّ خطأ بالشكل نفسه:**
```json
{ "message": "الرسالة التي يقرأها المستخدم", "errors": { "field": ["..."] } }
```

### الحرّاس
| الحارس | يفرض |
|---|---|
| `@login_required` | جلسة سارية غير مُبطَلة |
| `@admin_required` | العضوية الحالية `role='admin'` |
| **نطاق كل استعلام إداري** | **`org_id` وحده.** المشرف على مستوى الجمعية — `team_id` مرشّح واجهة **لا حاجز أمني** (`ARCHITECTURE.md` §٧.٣) |

## ٢. مسارات بنيوية — بلا متطلَّب وظيفي

| المسار | الطريقة | الغرض البنيوي | الحارس |
|---|---|---|---|
| `/health` | GET | **يفحص اتّصال القاعدة فعلًا** لا يردّ `200` أعمى | — |
| `/openapi.json` · `/docs` | GET | العقد المولَّد من `schemas/` | **معطَّل افتراضيًّا** — يُفعَّل بـ`EXPOSE_API_DOCS` |

**لماذا لا متطلَّب لها؟** لأنها تخدم **التشغيل لا المستخدم**: منصّة الاستضافة
تحتاج نقطة فحص، والمطوّر يحتاج العقد. **وهذا استثناء معلَن لا فجوة تتبّع** —
البوابة تشترط «متطلَّب **أو** غرض بنيوي موثَّق».

> `/health` يفحص القاعدة لأن خادمًا يردّ `200` وقاعدته ساقطة **يخدع المراقبة
> ويؤخّر اكتشاف العطل**.

## ٣. المصادقة

| المسار | الطريقة | الغرض | FR | الحارس |
|---|---|---|---|---|
| `/auth/login` | POST | دخول بـ`student_no` + PIN · قفل بعد ٥ محاولات | FR-001 · FR-003 | — |
| `/auth/logout` | POST | إبطال الجلسة **في القاعدة** | FR-002 | `login` |
| `/auth/me` | GET | المستخدم الحالي ودوره | FR-002 | `login` |

**`POST /auth/login`**
```json
→ { "student_no": "1042", "pin": "8317" }
← 200 { "user": { "id": 7, "full_name": "...", "role": "pilot" } }
```
| خطأ | الرمز | الرسالة |
|---|--:|---|
| بيانات خاطئة | 401 | **«رقم الطالب أو الرمز غير صحيح»** — رسالة **واحدة** للحالتين |
| حقل مجهول (مثل `org_id`) | 422 | يُرفض صاخبًا لا يُتجاهل صامتًا |
| قفل | 429 | «حاولت ٥ مرات. جرّب بعد ١٥ دقيقة.» — **يذكر متى** |

> 🔒 التفريق بين «رقم غير موجود» و«رمز خاطئ» يحوّل الشاشة إلى **أداة تعداد
> للطلاب**. الرسالة الواحدة ليست غموضًا بل ضمانة.
>
> **والزمن جزء من الرسالة.** بلا تهشير وهمي حين لا يوجد المستخدم، يردّ الرقم
> المجهول فورًا ويدفع الموجودُ كلفة argon2id — فارقٌ **مقيسٌ ٨.٩×** يعيد التعداد
> من باب آخر. `services/auth._DUMMY_HASH` يغلقه، و
> `test_unknown_student_costs_the_same_time_as_wrong_pin` يحرسه.

## ٤. الطيار

| المسار | الطريقة | الغرض | FR |
|---|---|---|---|
| `/me/deck` | GET | البطاقة: رتبة · ساعات · تقدّم · حالة | FR-010 · FR-011 · FR-013 |
| `/me/events` | GET | سجلّ الأحداث شاملًا التصحيحات | FR-012 |
| `/me/readings` | GET | طلبات قراءتي وحالاتها | FR-024 |
| `/me/readings` | POST | إرسال طلب قراءة | FR-020 · FR-021 |

**`GET /me/deck`** — **كل رقم محسوب في الخادم** (NFR: الواجهة تعرض ولا تحسب):
```json
{
  "rank":       { "name": "طيار أول", "tier": 2 },
  "hours":      "612.25",
  "next_rank":  { "name": "رائد سرب", "at_hours": "900.00",
                  "progress_pct": 42.5, "remaining": "287.75" },
  "flight":     { "grounded": false, "last_activity_on": "2026-08-28" },
  "team":       { "name": "سرب الفرقان", "rank_in_org": 2 }
}
```
- `progress_pct` **داخل الشريحة**: ٦١٢ ساعة نحو «رائد سرب» = **٤٢.٥٪ لا ٦٨٪**
  (ط-٣). الفرق بين الشريحة والمطلق هو أشيع خطأ في شرائط التقدّم.
- في أعلى رتبة: `next_rank: null` ← الواجهة تعرض **رسالة إتمام لا شريطًا ممتلئًا**.
- طالب بلا أحداث: `hours: "0.00"` و`rank.tier: 1` — **حالة مصمَّمة لا مكسورة**.

**`POST /me/readings`**
```json
→ { "read_on": "2026-08-29", "pages": 40, "book_title": "..." }
← 201 { "id": 88, "status": "pending" }
```
| خطأ | الرمز |
|---|--:|
| طلب مكرّر لنفس اليوم والكتاب | 409 |
| `pages ≤ 0` أو تاريخ مستقبلي | 422 |

**لا ساعات في الردّ** — الطلب لا يمنح شيئًا قبل الاعتماد (FR-021).

## ٥. اللوحات والتفاعل

| المسار | الطريقة | الغرض | FR |
|---|---|---|---|
| `/boards/pilots` | GET | صدارة الأفراد | FR-050 |
| `/boards/teams` | GET | صدارة الأسراب **بالمعدّل** | FR-051 · FR-052 |
| `/boards/formation` | GET | مشهد التشكيل | FR-053 |
| `/questions/today` | GET | سؤال اليوم | FR-060 |
| `/questions/{id}/answer` | POST | إجابة | FR-060 |
| `/notes` | POST | ملاحظة مجهولة | FR-061 |
| `/week/pilot` | GET | طيار الأسبوع وسببه | FR-062 |
| `/station` | GET | محطة التزوّد — وقود السرب | FR-072 |

**`GET /boards/teams`** — بالمعدّل لا بالمجموع، **وإلا صار الترتيب قياسًا للحجم**:
```json
[ { "team": "سرب الفرقان", "avg_hours": "412.30", "members": 6,
    "readiness": { "flying": 5, "grounded": 1 } } ]
```
`readiness` **عدّاد مجمّع بلا أسماء** — إشارة لوحة الجاهزية المحذوفة كصفحة.
**استعلام واحد بلا N+1** (ط-٧). **وفكّ التعادل بمعيار ثابت معلَن في الواجهة.**

**`GET /boards/formation`** — محكوم بـ**ف-١**:
```json
{ "scope": "team",
  "aircraft": [ { "name": "...", "size": 412.3, "grounded": false } ] }
```
| النطاق | يُعرض |
|---|---|
| داخل السرب | **الأسماء كاملة** شاملة الساقطين |
| الصدارة العامّة | **إنجاز فقط** — لا اسم لساقط |

**`POST /questions/{id}/answer`**
```json
→ { "choice_id": 2 }
← 200 { "correct": false, "correct_id": 3, "note": "الشرح...",
        "awarded_hours": "0.00" }
```
- **الجواب الصحيح وشرحه يظهران في الحالتين** — الخطأ فرصة تعلّم لا عقوبة (ط-٦).
- إجابة ثانية → **409** بقيد `UNIQUE` في القاعدة، **لا بإخفاء الزر**.
- «اليوم» **بتوقيت المنظمة لا المتصفّح**.

**`POST /notes`** → `201` بجسم فارغ. **لا `id` يُعاد** — معرّف يعود للمرسِل يخلق
خيط ربط حيث وعدنا ألّا يكون. الجهالة **بنية الجدول** (§٣ في `DATABASE.md`).

## ٦. المشرف

### اللصق والقرآن
| المسار | الطريقة | الغرض | FR |
|---|---|---|---|
| `/admin/paste/preview` | POST | **معاينة بلا كتابة** | FR-030 · FR-031 · FR-032 |
| `/admin/paste/commit` | POST | تنفيذ بعد المعاينة | FR-033 · FR-034 |
| `/admin/quran/entry` | POST | إضافة سجلّ ناقص يدويًّا | FR-036 |
| `/admin/events/{id}/reverse` | POST | تصحيح بحدث معاكس | FR-035 · FR-080 |

**`POST /admin/paste/preview`** — **لا يكتب شيئًا**:
```json
→ { "text": "الاسم\tحفظ\tمراجعة\tحضور\n..." }
← 200 {
  "batch_token": "…",
  "matched":   [ { "row": 1, "user_id": 7, "activities": {...} } ],
  "ambiguous": [ { "row": 2, "raw_name": "عبدالله السالم",
                   "candidates": [ {"user_id": 12, "score": 0.91} ] } ],
  "rejected":  [ { "row": 5, "reason": "لا مطابقة للاسم «...»" } ],
  "duplicates": 3
}
```
| القرار | لماذا |
|---|---|
| **مرحلتان (معاينة ← تنفيذ)** | الكتابة المباشرة تعني اكتشاف الخطأ بعد وقوعه |
| `ambiguous` **لا تُطبَّق تلقائيًّا** | مطابقة قريبة تنسب ساعات لطالب خطأ ولا يكتشفها أحد |
| `duplicates` معروض | يشرح للمشرف **لماذا** لم تُضَف صفوف — بلا شرح يظنّ أن النظام فشل |
| **الترويسة إلزامية** | عمودان متبادلان بصمت = أرقام معقولة الشكل خاطئة تمامًا |
| الحضور **عمود اختياري** | ف-١٠ — إن غاب فلا شيء يُكسر |

**`POST /admin/paste/commit`** — معاملة واحدة · idempotent بـ`external_ref` ·
**إعادة اللصق لا تضاعف** (اختبار إلزامي، م-١).

**`POST /admin/events/{id}/reverse`**
```json
→ { "reason": "خطأ في تصدير راصد — صفحات مضاعفة" }
← 201 { "id": 5012, "delta": "-40.00", "kind": "correction" }
```
> `reason` **إلزامي**. `422` بدونه. تصحيحٌ بلا سبب يبدو تلاعبًا في بطاقة الطالب.
> و**لا `UPDATE` ولا `DELETE`** — هذا هو ما يجعل مرونة التعديل الكاملة ممكنة
> بلا فقدان التاريخ.

### اعتماد القراءات
| المسار | الطريقة | الغرض | FR |
|---|---|---|---|
| `/admin/readings` | GET | الطابور، الأقدم أوّلًا | FR-022 |

**`POST /admin/readings/approve`** → `{ "ids": [88, 91, 94] }`
**الاعتماد الجماعي ليس رفاهية:** الاعتماد الفردي في طابور من ٢٠ طلبًا يخالف
NFR-02 مباشرةً.
**والحدث يُنشأ بـ`occurred_at = read_on`** لا وقت الاعتماد.

**الرفض** → `reason` إلزامي، **يراه الطالب** (FR-024). رفض صامت يقتل الثقة أسرع
من عدم وجود الميزة.

**`POST /admin/fuel/assess`** — الأوزان **تجمع ١٠٠٪ بالضبط** وإلا `422`:
> نشاط أوزانه ٩٥ يجعل الإتقان الكامل ٩٥٪، **فيظنّ السرب أنه قصّر وهو أتقن**.

الدرجات تُحفظ **مفصّلة** ليُشرح الرقم لاحقًا · `occurred_on` **تاريخ الوقوع**.

**`POST /admin/thresholds/preview`** — من يرتفع ومن ينخفض **قبل** الحفظ:
```json
← { "promoted": [...], "demoted": [], "warning": null }
```
**والرتبة لا تنخفض** (ف-٤): `demoted` يبقى فارغًا، ويُعرض كضمانة معلنة.
**سُلّم متناقض يُرفض** (`422`).

**`GET /admin/audit`** — **مفتوح لكل المشرفين لا لمالك المنظمة وحده.** هذا هو
التعويض الكامل عن دمج الدورين (`SCOPE.md` §٣.٣): الحماية **كشف الاستعمال** لا
**منع الصلاحية**. سجلٌّ يراه واحد فقط لا يحمي من شيء.

**`POST /admin/recalc`** → `{ "dry_run": true }` **افتراضيًّا**. الردّ يعرض
التسويات قبل تطبيقها، **ولا يُحذف شيء أبدًا** — تُصدَر أحداث تسوية.
