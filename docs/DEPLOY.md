# النشر — دليل عمليّ

> **صدقٌ أوّلًا:** كل أمر أدناه **اختُبر شكله محليًّا** (`docker-compose.yml`
> وهجرةٌ ودخولٌ حيّ)، لكن **التشغيل على خادم سحابيّ حقيقيّ لم يحدث بعد** —
> لا أحد يملك بيانات اعتمادك هنا. فجرّبه على نطاق ضيّق (طالبَين-ثلاثة) قبل
> الإعلان للجميع.
>
> وتصحيحٌ لِما كان مكتوبًا هنا خطأً حتى و-٢١: كانت هذه الوثيقة تقول «إنشاء
> المنظمة والطلاب الحقيقيين يقع عبر شاشات المشرف نفسها بعد أوّل نشر». **لم
> يكن ذلك صحيحًا** — لم يوجد مسارٌ واحد يُنشئ جمعيةً ولا طالبًا إلا
> `seed.py` (وهو يرفض الإنتاج). و-٢١ بنى الناقص: `flask bootstrap-org`
> وشاشة «الطلاب». أمّا الزعم القديم فمثالٌ على أسوأ خطأ في وثيقة نشر —
> يُكتشَف بعد النشر لا قبله.

## ١. المسار الأسرع: Render (مجانًا، بلا خادم)

المستودع يحمل `render.yaml`، فالنشر ثلاث نقرات: لوحة Render ⇒ **New** ⇒
**Blueprint** ⇒ اختر المستودع.

**مقايضتان صريحتان:** الخدمة المجانية **تنام بعد ١٥ دقيقة خمول** (أوّل زائر
بعدها ينتظر ~٥٠ ثانية)، وقاعدة البيانات المجانية **لها مدّة ثم تُحذف**. فهذا
للتجربة الأولى، لا لمئتَي طالب.

بعد أوّل نشر، خطوتان لا تُنسيان:

1. **`CORS_ALLOWED_ORIGINS`** — اضبطها على عنوان الخدمة
   (`https://asrab-xxxx.onrender.com`). وتركُها فارغةً **يمنع الإقلاع**
   صراحةً (حرس `assert_production_safe`) لا يكسر الكتابة صامتًا.
2. **التأسيس** — من Render Shell:
   ```bash
   flask bootstrap-org
   ```

## ٢. المسار الدائم: خادمٌ مجانيّ للأبد

| | التكلفة | الملاحظة |
|---|---|---|
| **Oracle Cloud Always Free** (موصى به) | **مجانًا للأبد** | ٤ OCPU ARM / ٢٤GB — فائضٌ واسع لمئتَي مستخدم. التسجيل يتحقّق ببطاقة **بلا سحب**، وخطأ «out of host capacity» شائعٌ يزول بالمحاولة على فترات |
| **Hetzner Cloud** (بديل فوريّ) | ~€٥/شهر | CX23 كافٍ بفائض، بلا تعقيد تسجيل |

بعد الحصول على خادم Ubuntu، **أمرٌ واحد**:

```bash
curl -fsSL https://raw.githubusercontent.com/Mohammed2254/ALASRAB/main/deploy/bootstrap.sh | bash
```

يثبّت دوكر · يستنسخ الكود · **يتوقّف ويطلب `.env.prod` بيدك** · يبني ويشغّل ·
يطبّق الهجرات · ويدلّك على أمر التأسيس. ولا يولّد سرًّا ولا يطبعه: سكربتٌ
يطبع كلمة مرور يُسرّبها إلى تاريخ الأوامر.

### الأسرار — بيدك لا بيد السكربت

```bash
cd ~/asrab-v2
cat > .env.prod << 'EOF'
DB_PASSWORD=<كلمة مرور طويلة عشوائية>
SECRET_KEY=<الناتج أدناه>
DOMAIN=<نطاقك، أو اتركه مع نفق Cloudflare>
EOF
python3 -c 'import secrets; print(secrets.token_urlsafe(48))'
```

**لا يُلمَس `docker-compose.prod.yml` لوضع سرٍّ فيه أبدًا** — كل قيمة من
`.env.prod` وحده (`NFR-09`)، وهو مُستبعَد من Git تلقائيًّا.

### طبقة HTTPS — واحدةٌ لا اثنتان

الدخول يستعمل كوكي `Secure`، فلا يعمل بلا HTTPS حقيقيّ. في
`docker-compose.prod.yml` خيارَان، **فعِّل واحدًا**:

- **عندك نطاق** (سجلّ A يشير للخادم): `caddy` مفعَّلة افتراضيًّا — لا شيء
  آخر، الشهادة تُصدَر عند أوّل تشغيل.
- **بلا نطاق:** عطِّل `caddy` وفعِّل `cloudflared`، ثم:
  ```bash
  docker compose -f docker-compose.prod.yml logs cloudflared | grep trycloudflare
  ```
  يعطيك `https://…trycloudflare.com` — HTTPS حقيقيّ بلا نطاق وبلا منفذٍ
  مفتوح (اتصالٌ صادرٌ فقط). **والرابط يتغيّر كل إعادة تشغيل** — للتجربة لا
  للإعلان.

## ٣. التأسيس — الخطوة التي بلا شيءٍ قبلها

قاعدةٌ جديدة فارغة: لا جمعية ولا مشرف ولا طالب. وهذا الأمر هو **المدخل
الوحيد**، ويعمل على قاعدةٍ فارغة وحدها ويرفض الثانية:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.prod \
  run --rm app flask bootstrap-org
```

يسأل عن اسم الجمعية وأوّل سرب واسم المشرف ورقم دخوله، ثم يطبع **رمزًا من
أربعة أرقام مرّةً واحدة**. اقرأه واحتفظ به — لا يُخزَّن نصًّا ولا يُعرض ثانيةً.

**ولماذا أمرُ طرفية لا شاشةُ تسجيل؟** مسارٌ عامّ يُنشئ جمعيةً ومشرفًا هو بابٌ
لمن يسبقك إليه. والطرفية داخل الحاوية صلاحيتُها صلاحيةُ الخادم نفسه — فلا
سطح هجوم جديد.

> **ولا بذرة تجريبية هنا:** `seed.py` بيانات وهمية للتطوير وحده، ورمزُها
> `1234` للجميع — وهو **يرفض الإقلاع** على بيئةٍ تبدو إنتاجًا أصلًا.

## ٤. الطلاب — من أين يأتون

من شاشة **الإدارة ⇒ الطلاب** بعد الدخول:

- **طالبٌ واحد**: اسم + رقم دخول ⇒ يولّد الخادم رمزه ويعرضه مرّة.
- **لصق قائمة**: سطر لكل طالب (`الاسم, رقم الطالب`) — الفاصلة أو التبويب.
  **والسطر الفاشل يُبلَّغ عنه وحده ولا يُسقط بقيّة اللصقة.** الرموز كلّها
  تُعرض مرّةً واحدة في بطاقةٍ لا تُغلق بنفسها.
- **لا حذف — تعطيل**: الحذف يتيّم أحداث الطالب في الدفتر (ADR-004).
  والتعطيل يُبطل جلساته فورًا، فكوكي عمرُه تسعون يومًا لا يبقى حيًّا.

ثم **الأوزان** و**العتبات**: القيم الأوّلية مؤلَّفة عن قصد (ف-٨) — تُعاد
معايرتها بعد شهر بيانات حقيقية، والصفر مشروع لتعطيل نشاط.

## ٥. التحديث لاحقًا

```bash
cd ~/asrab-v2 && git pull --ff-only
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build
# فقط إن أضافت الدفعة هجرة جديدة:
docker compose -f docker-compose.prod.yml --env-file .env.prod run --rm app flask db upgrade
```

الهجرة **يدويّة دائمًا** ولا تُشغَّل تلقائيًّا عند إعادة تشغيل الحاوية
(`ARCHITECTURE.md §٨`).

## ٦. النسخ الاحتياطي

```bash
./deploy/backup.sh
# يوميًّا ٣:١٥ فجرًا:
# 15 3 * * * cd $HOME/asrab-v2 && ./deploy/backup.sh >> ~/asrab-backup.log 2>&1
```

يُبقي آخر أربعة عشر يومًا، **ويرفض نسخةً فارغة**: `pg_dump` الفاشل عبر أنبوبٍ
يُنتج ملفًّا صالح الشكل خاوي المحتوى، فتُكتشَف الكارثة يوم الاستعادة لا يوم
النسخ.

**ونسخةٌ على القرص نفسه ليست نسخةً احتياطية** — انقلها خارج الخادم.
