# الشريحة الرأسية الأولى — و-١

> **معرَّفة لا منفَّذة.** لا يبدأ تنفيذها قبل نجاح البوابات الثلاث عشرة.

## الشريحة

> ### طالب واحد يدخل ويرى ساعاته الحقيقية.

من `seed` في القاعدة، إلى رقم محسوب في المحرّك، إلى JSON، إلى بطاقة على الشاشة.
**رأسية:** تخترق كل الطبقات مرّة واحدة لطالب واحد، ولا تُكمل أي طبقة.

### لماذا تشمل الدخول

`GET /me/deck` لا معنى له بلا هويّة، والبديل هويّة مزيّفة تُرمى لاحقًا **وتخفي
أخطر خطر تكامل عندنا**: كوكي `HttpOnly` بين Vite على منفذ وFlask على آخر —
CORS، و`SameSite`، وفحص `Origin` (ADR-006). **الشريحة الرأسية موجودة لتكشف هذا
مبكرًا**، فإخراجه منها يُبطل سببها.

### ما تُثبته قبل البناء فوقها

| # | تُثبت أن | ولو انكسر لاحقًا |
|---|---|---|
| ١ | القيد المركزي يعمل (ث-١) | كل حدث في المنصة مشكوك فيه |
| ٢ | الأوزان تُختار بـ`occurred_at` (ث-١١) | تعديل وزن يعيد كتابة الماضي |
| ٣ | النسبة **داخل الشريحة** لا مطلقة | كل شريط تقدّم في المنصة يكذب |
| ٤ | «أرضي» محسوبة بلا عمود (ث-١٤) | قيمة مشتقّة تفترق عن مصدرها |
| ٥ | الكوكي يعبر المنفذين | **إعادة تصميم المصادقة كلها متأخّرًا** |
| ٦ | الواجهة **تعرض ولا تحسب** | منطق مكرّر في مكانين يفترقان |

## ٢. تدفّق المستخدم

```
يفتح الرابط
  └─ لا كوكي ⇒ شاشة الدخول
       └─ يُدخل رقمه ورمزه
            ├─ خطأ ⇒ رسالة واحدة لا تفرّق بين الحالتين
            └─ صحيح ⇒ كوكي HttpOnly ⇒ بطاقة الطيار
                        ├─ رتبته وساعاته
                        ├─ شريط: ما بقي للرتبة التالية
                        └─ حالته: طائر / أرضي
```

**المسار البديل:** كوكي سارٍ ⇒ البطاقة مباشرةً بلا شاشة دخول.
**مسار الفشل:** كوكي مبطَل أو منتهٍ ⇒ `401` ⇒ العودة إلى الدخول بلا رسالة مخيفة.

## ٣. تدفّق البيانات

```
seed.py
  └─ org · user · team · membership
  └─ weight_version(effective_from) · weights · mastery_multipliers
  └─ rank_thresholds  (٠ · ٤٠٠ · ٩٠٠ · ١٥٠٠)
  └─ point_events  ← عبر services/ledger فقط  (ث-١٥)

POST /auth/login
  └─ argon2id.verify → sessions(token_hash) → Set-Cookie

GET /me/deck
  └─ security.@login_required → sessions
  └─ services/deck
       ├─ SUM(delta) WHERE scope='individual'      ← فهرس ٤.١
       ├─ rank_thresholds ⇒ الرتبة + النسبة داخل الشريحة
       └─ services/readiness ⇒ grounded            ← تُستدعى ولا يُعاد حسابها
  └─ schemas/me ⇒ JSON  (كل رقم محسوب)

الواجهة: تعرض ما وصل. صفر حساب.
```

## ٧. معايير القبول

**ملحوظة لا مفترَضة.** كلٌّ يمنع خطأً بعينه.

| # | المعيار | يمنع |
|---|---|---|
| ق-١ | رقم ورمز صحيحان ⇒ `200` + كوكي `HttpOnly; SameSite=Lax` | — |
| ق-٢ | رقم غير موجود ورمز خاطئ ⇒ **نفس الرسالة حرفيًّا ونفس الرمز** | تحويل الدخول إلى **أداة تعداد للطلاب** |
| ق-٣ | `/me/deck` بلا كوكي ⇒ `401` بلا تسريب | — |
| ق-٤ | `POST` بـ`Origin` أجنبي **أو بلا `Origin`** ⇒ `403` | **CSRF** (ADR-006) |
| ق-٥ | رصيد **٦١١.٢٥** ⇒ `rank="طيار أول"` و`progress_pct=**42.3**` | **النسبة المطلقة (٦٨٪) بدل نسبة الشريحة** |
| ق-٦ | طالب بلا أحداث ⇒ `hours="0.00"`، شاشة **مصمَّمة لا مكسورة** | الحالة الفارغة المنسيّة |
| ق-٧ | رصيد ١٥٠٠+ ⇒ `next_rank=null` و**رسالة إتمام لا شريط ممتلئ** | شريط ١٠٠٪ يوحي بأن هناك ما بعده |
| ق-٨ | آخر نشاط قبل ١٥ يومًا ⇒ `grounded=true`، **وبشكل ونصّ ولون معًا** | الاعتماد على اللون وحده |
| ق-٩ | بعد `logout` نفس الكوكي ⇒ `401` | **جوهر ADR-003** — لو نجح فالجلسة ليست في القاعدة |
| ق-١٠ | حدث بتاريخ ماضٍ + إصدار أوزان أحدث ⇒ **يُحتسب بالوزن القديم** | إعادة كتابة الماضي (ث-١١) |
| ق-١١ | الواجهة **بلا أي حساب**: فحص AST لا يجد مقارنة ولا عملية حسابية ولا رقم مجال | منطق مكرّر يفترق |
| ق-١٢ | `UPDATE` أو `DELETE` مباشر على `point_events` ⇒ **استثناء من القاعدة** | ث-٢ |
| **ق-١٣** | إطار **٣٧٥px** ⇒ **لا تمرير أفقي** | شاشة تُقصّ على أصغر جهاز شائع |
| **ق-١٤** | كل عنصر تفاعلي مرسوم **≥ 44×44px** | هدفٌ يُخطئه الإبهام |
| **ق-١٥** | `letter-spacing` المحسوب على كل عنصر **يحمل حروفًا عربية** = صفر | كسر وصل الحروف |
| **ق-١٦** | تباين محسوب من الألوان المرسومة **≥ 4.5:1** | نصّ لا يُقرأ في الشمس |

> **ق-١٣..ق-١٦ تُقاس في متصفّح حقيقي لا في DOM.** أثبت Part 5 الفرق: رمز `⛔`
> مرّ في ستة عشر اختبارًا وظهر **مربّعًا فارغًا** لأن الخطوط محلّية بلا خطّ
> إيموجي. **وجود العنصر ليس دليل ظهوره.**

## ٨. الاختبار

### ٨.١ الخريطة — معيار ← مالك تحقّق

**كل معيار يعلن مالكه، والمالك يعلن معياره.** والوسم `@covers ق-N` في الاختبار هو
الرابط الميكانيكي: `scripts/check-slice-gate.sh` يستخرج المعايير من هذا الملفّ
ويطابقها بما تعلنه الاختبارات فعلًا، **ومعيارٌ فقد مالكه يُسقط البوابة**.

| المعيار | المالك | الملفّ |
|---|---|---|
| ق-١ · ق-٢ · ق-٣ · ق-٩ | pytest | `api/tests/test_auth.py` |
| ق-٤ | pytest | `api/tests/test_csrf.py` |
| ق-٥ · ق-٦ · ق-٧ · ق-٨ · ق-١٠ | pytest | `api/tests/test_deck.py` |
| ق-١٢ | pytest | `api/tests/test_invariants.py` |
| ق-١١ | AST | `web/scripts/check-no-domain-logic.mjs` |
| ق-١٣..ق-١٦ (بصرية) | متصفّح حقيقي | `web/scripts/visual-qa.mjs` |
| — (تخويل) | pytest | `api/tests/test_authorization.py` |
| — (سلوك الواجهة) | vitest | `web/src/test/deck.test.jsx` |

**قاعدتان:** الاختبار **يشغّل الاستعلام الحقيقي** لا يفحص شكله · **بذرة نظيفة
لكل اختبار** (`TRUNCATE ... RESTART IDENTITY` ⇒ معرّفات حتمية).

### ٨.٢ ق-١١ — الواجهة تعرض ولا تحسب

```bash
cd web && npm run check:arch
```

> ⚠️ **استُبدل الأمر السابق لأنه لم يكن يكشف شيئًا.**
> كان `grep -nE '/|\*|>=|Math\.' web/src/pages/PilotDeck.jsx`، ونتيجته على
> ملفّ **نظيف** ٧٧ مطابقة: يطابق `//` و`/*` و`<br/>` وكل شرطة مائلة في JSX.
> **فحصٌ يطابق كل شيء يُدرَّب قارئه على تجاهله.**
>
> البديل يفحص **شجرة البناء لا النصّ**، بفئتين: مستهلكات العقد تُمنع من كل
> مقارنة وعملية حسابية ورقم مجال · والبدائيات البصرية تُمنع من لمس حقل مجال
> أصلًا، لأن حسابها إحداثيات SVG لا قاعدة عمل.

### ٨.٣ المعايير البصرية — تُقاس في متصفّح حقيقي

**اختبارات DOM لا تكفي هنا.** أثبت Part 5 ذلك عمليًّا: رمز `⛔` مرّ في ستة عشر
اختبارًا **وظهر مربّعًا فارغًا في المتصفّح** لأن الخطوط محلّية بلا خطّ إيموجي.
وجودُ العنصر في DOM لا يثبت أنه **مرئيّ ولا مقروء ولا قابل للمس**.

| المعيار | القياس | يمنع |
|---|---|---|
| **ق-١٣** | إطار **٣٧٥px** بلا تمرير أفقي (`scrollWidth ≤ clientWidth`) | شاشة تُقصّ على أصغر جهاز شائع |
| **ق-١٤** | `boundingBox()` لكل عنصر تفاعلي **≥ 44×44** | هدفٌ يُخطئه الإبهام |
| **ق-١٥** | `letter-spacing` المحسوب على **العناصر الحاملة حروفًا عربية** = صفر | كسر وصل الحروف |
| **ق-١٦** | نسبة التباين **المحسوبة من الألوان المرسومة** ≥ 4.5:1 | نصّ لا يُقرأ في الشمس |

> **ق-١٥ يفحص المحتوى لا الصنف.** حقل الرمز في `Login.jsx` يحمل
> `tracking-[0.3em]` وهو **سليم**: `type="password"` · `inputMode="numeric"` ·
> `maxLength={4}` ومخطّطه يفرض `^\d{4}$` — لا حرف عربي فيه، والأرقام لا تتّصل.
> فحصٌ بالصنف يسقطه كذبًا؛ والفحص بالمحتوى يمرّره بحقّ **ويسقطه لو دخلته عربية**.

> **ق-١٦ يقيس ولا ينقل.** النسب المعلنة في `VISUAL.md` أرقام مكتوبة —
> والقياس على العناصر المرسومة هو ما يثبتها.

### ٨.٥ الإثبات العدائي — شرط قبول لا خيار

**فحصٌ لم يُثبَت أنه يكشف مخالفته ادّعاءٌ لا فحص.** لكل بوابة أُضيفت، زُرعت
أصغر مخالفة مقصودة وأُثبت السقوط، ثم استُعيد الأصل وأُعيد التشغيل:

| البوابة | المخالفة المزروعة | السقوط الفعلي |
|---|---|---|
| التتبّع | إزالة وسم `@covers ق-٧` | `❌ معايير بلا مالك: ق-٧` · خروج ١ |
| التتبّع (حارس الفراغ) | إفراغ جدول §٧ | `❌ استُخرج 0 معيارًا (الحدّ ١٢)` · خروج ١ |
| ق-١٣ | عنصر عرضه 900px | `تمرير أفقي — 916px داخل 375px` |
| ق-١٤ | زرّ 30×30 | `«خروج» 30×30 < 44` |
| ق-١٥ | `tracking-[0.2em]` على الاسم | `«بندر الشمري» letter-spacing=5.2px` |
| ق-١٦ | لون `concrete` على نصّ 12px | `تباين 3.5:1 < 4.5` |

> **حارس الفراغ ليس ترفًا.** أوّل نسخة من `check-slice-gate.sh` فشل فيها استخراج
> الأرقام العربية-الهندية بصمت (عطل محليّة)، **فأعلنت النجاح على صفر معايير**.
> بوابةٌ تمرّ على لا شيء أسوأ من غيابها — فصار `MIN_CRITERIA` شرطًا.
