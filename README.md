# الأسراب

منصة تنافس وتحفيز لطلاب جمعية قرآنية شبابية. طبقة تنافس **فوق** إنجاز موجود:
لا تُدير الحلقة ولا تسجّل التسميع، بل تأخذ ما أُنجز وتحوّله إلى تقدّم مرئي.

**الحالة:** **Stage 4 قيد التنفيذ.** الخلفية ٤٤/٤٥ متطلَّبًا (`FR-086` مؤجَّل
عمدًا)، والواجهة (`ui/`) ٢٥/٢٥ شاشة — **أمر التشغيل الحيّ يشير إليها الآن**
(`web/` مرجعٌ مجمَّد للانحدار وحده). الباقي: النشر (لا `Dockerfile` ولا CI
ولا HTTPS بعد). **كل رقم هنا لقطة — [`docs/HANDOFF.md`](docs/HANDOFF.md)
هو المصدر الحيّ.**
